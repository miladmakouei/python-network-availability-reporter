

# Network Availability Reporter

ابزار خط فرمانی برای بررسی دسترسی چند مقصد شبکه و تهیه گزارش CSV.

برنامه فهرست مقصدها را از یک فایل متنی می‌خواند، برای هرکدام تست Ping انجام می‌دهد و نتیجه را همراه با زمان بررسی در یک فایل CSV ذخیره می‌کند.

## امکانات

- خواندن فهرست مقصدها از فایل متنی
- پشتیبانی از نام دامنه و آدرس IP
- حذف مقصدهای تکراری
- بررسی چند مقصد در یک اجرا
- نمایش وضعیت پاسخ‌گویی هر مقصد
- اندازه‌گیری مدت‌زمان اجرای دستور Ping
- ذخیره نتایج در CSV
- نمایش خلاصه وضعیت مقصدها

## فناوری‌های استفاده‌شده

- Python 3
- `subprocess`
- `csv`
- `pathlib`
- `datetime`
- `platform`

این پروژه به کتابخانه خارجی نیاز ندارد.

## راه‌اندازی

ابتدا مخزن را دریافت کنید و وارد پوشه پروژه شوید.

فایل `targets.txt` را باز کنید و مقصدهای موردنظر را در آن قرار دهید.

هر مقصد باید در یک خط جداگانه نوشته شود.

## اجرا

```bash
python3 main.py
```

پس از پایان بررسی، فایل `network_report.csv` در پوشه پروژه ساخته می‌شود.

## فرمت گزارش

گزارش شامل چهار ستون است:

| ستون | توضیح |
|---|---|
| target | مقصد بررسی‌شده |
| status | وضعیت پاسخ‌گویی |
| response_ms | مدت‌زمان اجرای دستور Ping برحسب میلی‌ثانیه |
| checked_at | زمان انجام بررسی |

## وضعیت‌های ممکن

- `ONLINE`: مقصد به Ping پاسخ داده است.
- `OFFLINE`: مقصد به Ping پاسخ نداده است.
- `TIMEOUT`: اجرای دستور از محدودیت زمانی عبور کرده است.
- `PING_NOT_FOUND`: دستور Ping در سیستم پیدا نشده است.

## محدودیت‌ها

- بررسی دسترسی بر اساس ICMP Ping انجام می‌شود.
- پاسخ ندادن به Ping لزوماً به معنی قطع بودن سرویس نیست.
- زمان گزارش‌شده، مدت اجرای دستور Ping است و RTT دقیق شبکه محسوب نمی‌شود.
- برنامه در هر اجرا یک گزارش جدید ایجاد می‌کند و گزارش قبلی را جایگزین می‌کند.
- بررسی مقصدها به‌صورت ترتیبی انجام می‌شود.
